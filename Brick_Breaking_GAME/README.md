# 🧱 무한의 벽돌 (Brick Breaking Game)

> **OpenGL 기반 벽돌깨기 게임**
> 베지어 곡선 패들과 사분면별 중력을 직접 구현한 물리 기반 아케이드 게임

---

## 💡 프로젝트 개요

전통적인 벽돌깨기(Breakout) 공식에 두 가지 변형을 더한 게임입니다. 패들이 직선이 아니라 2차 베지어 곡선으로 그려지며 좌우 방향키로 회전시킬 수 있고, 공에는 화면을 4분면으로 나눠 방향이 바뀌는 독특한 중력이 적용됩니다. 대학교 "컴퓨터 그래픽스" 과목 프로젝트로 제작했습니다.

---

## ✨ 주요 기능

- **베지어 곡선 패들** — 3개의 제어점으로 정의된 2차 베지어 곡선을 패들로 사용, 방향키로 회전
- **접선/법선 기반 반사** — 곡선 위 충돌 지점의 접선을 계산해 법선 방향으로 공을 반사
- **사분면 중력** — 공의 위치(사분면)에 따라 중력 방향이 바뀌는 커스텀 물리
- **점수/하이스코어/라이프 시스템** — 벽돌 파괴 시 점수 획득, 라이프 소진 시 리셋
- **승리 이펙트** — 반짝이는 텍스트 애니메이션으로 승리 연출
- **무한 리스폰 벽돌** — 벽돌을 모두 깨면 자동으로 다시 생성되어 무한 플레이 가능

## 🚀 빌드 및 실행 방법

Visual Studio 2022에서 `Brick_Breaking_GAME.sln`을 열고 `x64 | Debug` 구성으로 빌드하면 NuGet 패키지(nupengl.core)가 자동 복원됩니다.

```powershell
# 또는 MSBuild로 직접 빌드
MSBuild Brick_Breaking_GAME.sln /p:Configuration=Debug /p:Platform=x64 /t:Restore,Build
```

빌드 결과물은 `x64/Debug/Brick_Breaking_GAME.exe`에 생성됩니다.
